# Create Specification

When this command is invoked:

1. Analyze the user's feature request.
2. Ask clarifying questions if requirements are ambiguous.
3. Produce a Software Requirements Specification containing:
   - Overview
   - Functional Requirements
   - Non-functional Requirements
   - User Stories
   - Acceptance Criteria
   - API Requirements
   - Database Changes
   - UI Requirements
   - Error Handling
   - Security
   - Test Cases
4. Save the specification in:

docs/specs/<feature-name>.md

Use Markdown formatting.
